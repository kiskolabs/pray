# Push Homebrew pray 1.16.0

## Participants

Andrei Makarov

## Decisions

Push amkisko/homebrew-tap main so Formula/pray.rb matches the tagged v1.16.0 archive. make bump-homebrew had already committed v1.12.0 through v1.16.0 locally. It does not pass --push, so origin stayed on v1.11.0. The v1.12.0 phrasing in later tag notes was copied from the 1.12.1 pass and did not match GitHub.

## Effects

git push of amkisko/homebrew-tap moved origin/main from 1829aaf to 8e4e62b. GitHub Formula/pray.rb now uses https://github.com/kiskolabs/pray/archive/refs/tags/v1.16.0.tar.gz with sha256 9992a922eb345f295fc9c792bbff677be0a5a907a6d3c4a51bfb8674095d48bc. That digest matches shasum -a 256 of the published tarball.
