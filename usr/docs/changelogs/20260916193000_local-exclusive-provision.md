# Local exclusive tree and file provision

## Participants

Andrei Makarov

## Decisions

RFC 0115 proposed exclusive copy of a project-local file or directory. That proposal is not adopted. Local compose embeds stay. Package file: and tree stay.

A later pass rewrote the RFC so Status Rejected matches the body. Fail-parse stays in RFC 0010.

## Effects

Those Prayfile forms fail parse.
