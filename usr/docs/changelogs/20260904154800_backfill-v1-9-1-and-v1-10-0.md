# Backfill tags v1.9.1 and v1.10.0

## Participants

Andrei Makarov

## Decisions

Cut historical annotated tags and GitHub Releases for already-published registry versions 1.9.1 and 1.10.0. Keep v1.11.0 as the latest GitHub Release. Leave Homebrew on v1.11.0. Do not republish crates.io, npm, or RubyGems.

Create a GitHub Release from an existing tag with gh release create --verify-tag --latest=false and omit --target. --target needs a branch or full commit SHA; a short SHA returns HTTP 422.

## Effects

Annotated tag v1.9.1 points at bb422ff. GitHub Release https://github.com/kiskolabs/pray/releases/tag/v1.9.1 is published.

Annotated tag v1.10.0 points at 2a66fbf. GitHub Release https://github.com/kiskolabs/pray/releases/tag/v1.10.0 is published.

Latest GitHub Release remains v1.11.0. amkisko/homebrew-tap Formula/pray.rb stays on v1.11.0.
