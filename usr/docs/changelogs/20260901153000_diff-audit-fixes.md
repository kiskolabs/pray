## Effects

TypeScript and Ruby HTTP clients cap response bodies at 64 MiB, matching Rust. Ruby reads the body inside the Net::HTTP request block so the cap applies while streaming.

Verification codes are high-entropy secrets stored as hashes. Public verify returns one failure shape and stops after five guesses. The auth database uses owner-only file mode on Unix.

Ruby and TypeScript unpack tar members themselves after checksum verification. They no longer pipe the archive to system tar. Unpack skips AppleDouble sidecar members. Encode sets COPYFILE_DISABLE so macOS tar does not add those members.

TypeScript verifies a present registry signature. Remote artifact fields must be relative paths. Package names are validated before TypeScript metadata URLs.

Passkey and SSH store login helpers that issued sessions without a signature are removed. Challenge consume runs in one immediate SQLite transaction. Enroll refuses to move an authenticator to another email.

TypeScript serve 500 bodies are a fixed internal error string. Ruby index HTML no longer prints the filesystem root. Rust HTTP RPC ids increment per request.
