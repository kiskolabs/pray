# Local prayers as path-source packages

## Participants

Andrei Makarov

## Decisions

Consumer projects keep local prayers under a path source directory without a version until pack or publish. The folder name is the author's. pray prayer init with a Prayfile scaffolds that tree and declares the prayer once. .agents/project.md remains a one-file compose shortcut.

A later pass locates the tree through source path: instead of pray path: so compose does not name the same prayer twice.

A later pass declares pray "local/project" so the source handle is in the package token.

## Effects

An unversioned path-source package locks as local. pray package fails until spec.version is set.
