## Decisions

Unblock rust, npm, and ruby jobs without changing the user-facing CLI contract. rustfmt the rfc_ids scratch path join. Pin npmjs/pray-cli typescript to ~5.9.3 and @types/node to ^22.15.0. Add npm overrides for js-yaml, nanoid, and postcss. Ignore Dependabot semver-major updates for typescript and @types/node. Add gem json >= 2.21.2 in the development group and lock 2.21.2.

No CHANGELOG.md bullet. These are CI and development-tooling gates.
