# Prepare 1.18.1 gem-only release

## Participants

Andrei Makarov

## Decisions

Cut RubyGems 1.18.1 for the missing tmpdir load on pray package and pray publish. Leave workspace, crates.io, and npm at 1.18.0. Rust and TypeScript CLIs do not call Dir.mktmpdir. Tag v1.18.1. Do not cargo publish or npm publish from this pass.

make release-rubygems reads Pray::VERSION. When that version differs from the workspace, it warns and still builds the gem. make release-all and crates/npm still require version alignment.

## Effects

Pray::VERSION is 1.18.1. Workspace Cargo.toml and npmjs/pray-cli stay 1.18.0. bundle lock rewrote Gemfile.lock PATH gem to 1.18.1 and did not bump unrelated gems.

./scripts/release/changelog_test.sh printed changelog notes tests passed. ./scripts/release/github.sh --notes-only --version 1.18.1 printed the 1.18.1 heading and the staging-directory bullet.

./scripts/release/rubygems.sh --dry-run warned gem 1.18.1 does not match workspace 1.18.0; publishing gem only. It built pray-cli 1.18.1 (305 examples, 0 failures).

Later pass 20260917185200: annotated tag v1.18.1 points at a3f5ba1. No crates.io or npm publish from this pass.

Push v1.18.1 and gem push pray-cli 1.18.1. Leave Homebrew on the Rust tag v1.18.0. Next coordinated version for crates.io and npm is 1.18.2 or later. Do not publish those surfaces as 1.18.1.
