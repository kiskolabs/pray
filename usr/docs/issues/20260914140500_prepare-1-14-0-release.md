# Prepare 1.14.0 release

## Participants

Andrei Makarov

## Decisions

Cut 1.14.0 from RFC 0061 publish-version-preservation and cross-CLI compose and manifest hash parity. Minor bump: local publish keeps an unchanged package version's artifact, first-publish time, and yank; registry and federation JSON write published_at as UTC Unix seconds; composed files and canonical manifest JSON match across CLIs. Keep 2.0.0 for removing deprecated target, output, agent, skills, skill, and spec.skills. RFC 0061 stays Proposed through 2026-09-28. Leave Dependabot branches unmerged. Do not tag or publish from this pass.

## Effects

Workspace Cargo.toml, npmjs/pray-cli package.json, TypeScript PACKAGE_VERSION, and Ruby Pray::VERSION all read 1.14.0. bundle lock in rubygems/pray-cli rewrote Gemfile.lock with PATH gem pray-cli 1.14.0 and did not bump unrelated gems. cargo check --workspace --locked finished. cargo run -p pray-cli --locked -- install rewrote Prayfile.lock generated_by from pray 1.13.0 to pray 1.14.0. Package pins and hashes stayed the same. manifest_hash stayed sha256:a341f184fec96530f771b87a188108aa3e273973211c6f592283b890b7d38b0b.

make release-dry-run finished. pray-core 1.14.0 packaged (150 files, 786.6KiB, 157.6KiB compressed) and the upload aborted for dry-run. pray-transport and pray-cli dry-run fell back to cargo check because crates.io still has pray-core 1.13.0. npm pack produced pray-cli 1.14.0 (166 tests passed, 0 failed; package size 237.4 kB). Ruby gem build produced pray-cli 1.14.0 (218 examples, 0 failures).

No tag and no registry publish from this pass.

## Next

Publish crates.io, npmjs, and RubyGems through the manual release process. Then bump Homebrew.
