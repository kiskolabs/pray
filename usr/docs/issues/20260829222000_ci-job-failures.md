# CI jobs failed before tests

## Participants

Andrei Makarov

## Decisions

Repair the three GitHub Actions jobs that failed on main at merge 123662f (CI run 33270173050). Keep TypeScript on the 5.9 line until madge accepts a newer peer. Keep @types/node on the 22 line while CI runs Node 22. Floor the development json gem at 2.21.2 so bundler-audit can pass. rustfmt the rfc_ids scratch helper so cargo fmt --check passes.

## Effects

cargo fmt --check failed on crates/pray-core/tests/rfc_ids/main.rs. npm ci failed with ERESOLVE because Dependabot PR 12 set typescript to ^7.0.2 while madge 8.0.0 still declares peerOptional typescript ^5.4.4. bundle exec bundler-audit check --update failed on json 2.21.1 (CVE-2026-71847). After npm ci, npm audit would also have flagged js-yaml, nanoid, and postcss; those are pinned through package.json overrides. After TypeScript compiled against @types/node 26 on Node 22, ssh-agent chunk typing would have broken; pinning types to 22 removed that without a source change.

Local checks after the patch: cargo fmt --all --check, cargo clippy --workspace --all-targets -D warnings, cargo test --workspace, make loc-check (122 warnings, 0 failures), npm ci, npm test (83 pass), npm run lint, npm audit (0 vulnerabilities), bundle exec bundler-audit check --update, make lint in rubygems/pray-cli, POLYRUN_COVERAGE=1 bundle exec polyrun parallel-rspec --workers 5 --merge-failures.
