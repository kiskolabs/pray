# Prepare 1.12.1 release

## Participants

Andrei Makarov

## Decisions

Cut 1.12.1 from the git catalog refresh and RFC 0071 ignore-.pray work already on main. Patch bump: install refreshes a locked git catalog when a newly declared package is missing from the pinned revision, and the error names that revision with pray update if it is still missing. Recommend ignoring the project .pray directory. Keep 2.0.0 for removing deprecated target, output, agent, skills, skill, and spec.skills.

Do not tag or publish from this pass.

## Effects

Workspace Cargo.toml, npmjs/pray-cli package.json, TypeScript PACKAGE_VERSION, and Ruby Pray::VERSION all read 1.12.1. cargo check --workspace --locked finished. cargo run -p pray-cli --locked -- install rewrote Prayfile.lock generated_by from pray 1.12.0 to pray 1.12.1. Package pins and hashes stayed the same.

make release-dry-run finished. pray-core 1.12.1 packaged (137 files, 746.3KiB) and the upload aborted for dry-run. pray-transport and pray-cli dry-run fell back to cargo check because crates.io still has pray-core 1.12.0. npm pack produced pray-cli 1.12.1 (156 tests passed, 0 failed; package size 229.9 kB). Ruby gem build produced pray-cli 1.12.1 (206 examples, 0 failures).

## Next

Tag v1.12.1 and publish the GitHub Release. Then publish crates.io, npmjs, and RubyGems through the manual release process. Then bump Homebrew.
