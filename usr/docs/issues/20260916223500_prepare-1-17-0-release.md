# Prepare 1.17.0 release

## Participants

Andrei Makarov

## Decisions

Cut 1.17.0 from local prayers, path-fork first material, local exclusive refuse, help pairs, distribution protocols, torrent publish parity, spec.maintainers, spec.pray_version, and local compose checksums. Minor bump: operators can init a local prayer as pray "local/project", copy upstream into an empty path fork, opt in to .praytorrent.json with protocols torrent, and re-embed a changed local compose source on install. Keep 2.0.0 for removing deprecated target, output, agent, skills, skill, and spec.skills. RFC 0116, RFC 0117, and RFC 0062 stay Experimental or Proposed. Leave Dependabot branches unmerged. Do not tag or publish from this pass.

## Effects

Workspace Cargo.toml, npmjs/pray-cli package.json, TypeScript PACKAGE_VERSION, and Ruby Pray::VERSION all read 1.17.0. bundle lock in rubygems/pray-cli rewrote Gemfile.lock with PATH gem pray-cli 1.17.0 and did not bump unrelated gems. cargo check --workspace --locked finished. cargo run -p pray-cli --locked -- install rewrote Prayfile.lock generated_by from pray 1.16.0 to pray 1.17.0. Package pins stayed the same. manifest_hash stayed sha256:54f67e7f0bba02adc72e1dbc830961fe7b43d7cd11e04fdce3563661fe3cbaa8. Install added a managed span for .agents/project.md and wrapped that section in AGENTS.md.

make release-dry-run packaged pray-core 1.17.0 (170 files, 859.2KiB, 171.1KiB compressed) and the upload aborted for dry-run. pray-transport and pray-cli dry-run fell back to cargo check because crates.io does not have pray-core 1.17.0. npm pack produced pray-cli 1.17.0 (238 tests passed, 0 failed; package size 287.6 kB). First gem lint failed on CyclomaticComplexity in apply_assignment and parser_spec indentation. After those two fixes, ./scripts/release/rubygems.sh --dry-run built pray-cli 1.17.0 (299 examples, 0 failures).

No tag and no registry publish from this pass.

## Next

Tag v1.17.0 and publish crates.io, npmjs, and RubyGems through the manual release process.
