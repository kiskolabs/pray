# Prepare 1.15.0 release

## Participants

Andrei Makarov

## Decisions

Cut 1.15.0 from the RFC 0114 path-fork refresh, update --latest pin rewrite, pack uniqueness, and in-process CLI context work already on main. Minor bump: Rust, Ruby, and TypeScript refresh a path fork on pray update; pray update --latest rewrites a spec.upstream pin that does not admit the latest upstream version, then refreshes; Ruby pray update --latest rewrites Prayfile constraints the same way; published registry metadata does not echo spec.upstream; pack refuses a repeated or aliased archive path; a later Ruby or TypeScript install uses the current project after an earlier in-process command in another directory. Keep 2.0.0 for removing deprecated target, output, agent, skills, skill, and spec.skills. RFC 0114 stays Experimental. Leave Dependabot branches unmerged. Do not tag or publish from this pass.

## Effects

Workspace Cargo.toml, npmjs/pray-cli package.json, TypeScript PACKAGE_VERSION, and Ruby Pray::VERSION all read 1.15.0. bundle lock in rubygems/pray-cli rewrote Gemfile.lock with PATH gem pray-cli 1.15.0 and did not bump unrelated gems. cargo check --workspace --locked finished. cargo run -p pray-cli --locked -- install rewrote Prayfile.lock generated_by from pray 1.14.0 to pray 1.15.0. Package pins and hashes stayed the same. manifest_hash stayed sha256:a341f184fec96530f771b87a188108aa3e273973211c6f592283b890b7d38b0b.

make release-dry-run finished. pray-core 1.15.0 packaged (151 files, 798.0KiB, 159.6KiB compressed) and the upload aborted for dry-run. pray-transport and pray-cli dry-run fell back to cargo check because crates.io still has pray-core 1.14.0. npm pack produced pray-cli 1.15.0 (186 tests passed, 0 failed; package size 254.3 kB). Ruby gem build produced pray-cli 1.15.0 (242 examples, 0 failures).

No tag and no registry publish from this pass.

Later pass 20260915105000: annotated tag v1.15.0 points at ffbd703. GitHub Release https://github.com/kiskolabs/pray/releases/tag/v1.15.0 is published. No registry publish. Homebrew stayed on v1.12.0.

Publish crates.io, npmjs, and RubyGems through the manual release process. Then bump Homebrew.
