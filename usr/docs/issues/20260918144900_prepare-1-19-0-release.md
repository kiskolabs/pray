# Prepare 1.19.0 release

## Participants

Andrei Makarov

## Decisions

Cut 1.19.0 from named Prayfile publish remotes already on main (RFC 0118). Minor bump: operators declare publish remotes, pray publish uses them when dest flags are omitted, and only path-owned packages publish. Skip 1.18.1 as a coordinated number because that cut was Ruby-only. Keep 2.0.0 for removing deprecated target, output, agent, skills, skill, and spec.skills. RFC 0118 stays Experimental. Leave Dependabot branches unmerged. Do not tag or publish from this pass. Leave Homebrew until registry publish.

## Effects

Workspace Cargo.toml, npmjs/pray-cli package.json, TypeScript PACKAGE_VERSION, and Ruby Pray::VERSION all read 1.19.0. bundle lock in rubygems/pray-cli rewrote Gemfile.lock with PATH gem pray-cli 1.19.0 and did not bump unrelated gems. cargo check --workspace --locked finished. cargo run -p pray-cli --locked -- install rewrote Prayfile.lock generated_by from pray 1.18.0 to pray 1.19.0. Package pins stayed the same. manifest_hash stayed sha256:80582fcd5c25b03373e3b837d46233f09419014505e2ac7e5974e171f08860ca.

make release-dry-run packaged pray-core 1.19.0 (187 files, 943.3KiB, 185.7KiB compressed) and the upload aborted for dry-run. pray-transport and pray-cli dry-run fell back to cargo check because crates.io does not have pray-core 1.19.0. npm pack produced pray-cli 1.19.0 (257 tests passed, 0 failed; package size 305.1 kB). ./scripts/release/rubygems.sh --dry-run built pray-cli 1.19.0 (318 examples, 0 failures). ./scripts/release/changelog_test.sh printed changelog notes tests passed. ./scripts/release/github.sh --notes-only --version 1.19.0 printed the 1.19.0 heading and the publish-remotes bullet. ./scripts/release/versions_test.sh printed coordinated version tests passed, including live next coordinated version 1.19.0.

Operator surface assessed: pray help publish. Hierarchy is a one-line action, then Usage with dest flags, then remotes and signing-key copy. Interactive flags are --root, --server, --to, --dry-run, and --signing-key. Empty dest with remotes is the omitted-flag path. A person can finish publish from that help when remotes exist or dest flags are known. Remaining for a human: pray help repo still says only scaffold a distribution root and does not mention appending a prayers remote.

No tag and no registry publish from this pass.

## Next

Tag v1.19.0 and publish the GitHub Release. Then publish crates.io, npmjs, and RubyGems through the manual release process. Then bump Homebrew with make bump-homebrew.
