## Effects

Workspace Cargo.toml, npmjs/pray-cli package.json, TypeScript PACKAGE_VERSION, and Ruby Pray::VERSION all read 1.12.0. cargo check --workspace --locked finished. cargo run -p pray-cli --locked -- install rewrote Prayfile.lock generated_by from pray 1.11.0 to pray 1.12.0. Package pins and hashes stayed the same.

make release-dry-run finished. pray-core 1.12.0 packaged (136 files) and the upload aborted for dry-run. pray-transport and pray-cli dry-run fell back to cargo check because crates.io still has pray-core 1.11.0. npm pack produced pray-cli 1.12.0 (153 tests passed, 0 failed; package size 226.8 kB). Ruby gem build produced pray-cli 1.12.0 (203 examples, 0 failures).

No tag, no GitHub Release, no registry publish.

## Next

Tag v1.12.0 and publish crates.io, npmjs, and RubyGems through the manual release process when approved. Then create the GitHub Release and bump Homebrew.
