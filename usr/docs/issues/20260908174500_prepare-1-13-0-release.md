# Prepare 1.13.0 release

## Participants

Andrei Makarov

## Decisions

Cut 1.13.0 from the RFC 0114 package-upstream work staged for main. Minor bump: a path package may declare one upstream pin; install records and verifies it; Rust update refreshes a path fork; npm and RubyGems refuse that update until they can refresh the path tree. Keep 2.0.0 for removing deprecated target, output, agent, skills, skill, and spec.skills.

Optional upstream fields on public Rust structs follow the same serde-default pattern as provisioned in 1.10.0. Callers that construct those structs by field list remain a later major or redesign. Leave Dependabot branches unmerged. Do not tag or publish from this pass.

## Effects

Workspace Cargo.toml, npmjs/pray-cli package.json, TypeScript PACKAGE_VERSION, and Ruby Pray::VERSION all read 1.13.0. cargo check --workspace --locked finished. cargo run -p pray-cli --locked -- install rewrote Prayfile.lock generated_by from pray 1.12.1 to pray 1.13.0. Package pins and hashes stayed the same.

make release-dry-run finished. pray-core 1.13.0 packaged (149 files, 783.6KiB) and the upload aborted for dry-run. pray-transport and pray-cli dry-run fell back to cargo check because crates.io still has pray-core 1.12.1. npm pack produced pray-cli 1.13.0 (160 tests passed, 0 failed; package size 233.1 kB). Ruby gem build produced pray-cli 1.13.0 (210 examples, 0 failures).

Later pass 20260908174400: annotated tag v1.13.0 points at fad6e86. GitHub Release https://github.com/kiskolabs/pray/releases/tag/v1.13.0 is published. No registry publish. Homebrew stayed on v1.12.0.

## Next

Publish crates.io, npmjs, and RubyGems through the manual release process. Then bump Homebrew.
