# Prepare 1.16.0 release

## Participants

Andrei Makarov

## Decisions

Cut 1.16.0 from the RFC 0109 embedder surface, RFC 0100 fixture packs, RFC 0106 dest inspect, tarball resolve, Ruby and TypeScript cycle reject, and Ruby update --latest pessimistic rewrite already on main. Minor bump: Rust lists pray_core::embed for parse, resolve, lock, render, and verify; all three libraries resolve a local tarball: archive, refuse two-package dependency cycles, and inspect locked dest spans without resolve; Ruby pray update --latest rewrites a two-component pessimistic pin and installs a newer version the current constraint already allows. Keep 2.0.0 for removing deprecated target, output, agent, skills, skill, and spec.skills. RFC 0100, RFC 0106, and RFC 0109 stay Experimental. The rustls 0.23.45 lock bump already on main stays out of CHANGELOG.md. Leave Dependabot branches unmerged. Do not tag or publish from this pass.

## Effects

Workspace Cargo.toml, npmjs/pray-cli package.json, TypeScript PACKAGE_VERSION, and Ruby Pray::VERSION all read 1.16.0. bundle lock in rubygems/pray-cli rewrote Gemfile.lock with PATH gem pray-cli 1.16.0 and did not bump unrelated gems. cargo check --workspace --locked finished. cargo run -p pray-cli --locked -- install rewrote Prayfile.lock generated_by from pray 1.15.0 to pray 1.16.0. Package pins and hashes stayed the same. manifest_hash stayed sha256:a341f184fec96530f771b87a188108aa3e273973211c6f592283b890b7d38b0b.

make release-dry-run finished. pray-core 1.16.0 packaged (161 files, 825.6KiB, 164.6KiB compressed) and the upload aborted for dry-run. pray-transport and pray-cli dry-run fell back to cargo check because crates.io still has pray-core 1.15.0. npm pack produced pray-cli 1.16.0 (202 tests passed, 0 failed; package size 262.1 kB). Ruby gem build produced pray-cli 1.16.0 (264 examples, 0 failures).

No tag and no registry publish from this pass.

## Next

Publish crates.io, npmjs, and RubyGems through the manual release process. Then bump Homebrew.
