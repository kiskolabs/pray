# pray-transport

Transport adapters for [pray](https://pray.kisko.dev) distribution points: HTTP registry access, federation sync, and related peer transports.

Used by the `pray` CLI when talking to remote or peer distribution points.

## Install

```toml
[dependencies]
pray-transport = "1.5"
```
