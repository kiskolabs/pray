# Prepare 1.26.0 release

## Decisions

Prepare version 1.26.0 dated 2026-10-30 without committing, tagging, pushing, or publishing. Keep the Unreleased headings empty and move the coordinated release notes under the dated version heading.

Treat the AUR checksum as a post-tag task because the 1.26.0 source archive does not exist during preparation.

## Effects

The Rust workspace, npm and JSR packages, Ruby gem, lockfiles, generated-by markers, package metadata, and four changelogs now agree on version 1.26.0.

The release dry run completed. The unpublished pray-core 1.26.0 dependency prevented Cargo from resolving dependent crates from crates.io, so the release script used its expected local cargo check fallback for pray-transport and pray-cli. npm and JSR package dry runs and the Ruby gem build completed without publishing. JSR reported Node's DEP0190 warning from its command wrapper. RubyGems reported that two metadata keys share one URI.

The full Rust workspace first found a parallel-test temporary-directory collision. The new regression test failed with the old clock-only name. The fixture now atomically reserves a directory identified by process, clock value, and sequence. The regression test, seven update destination tests, and the full workspace then passed.

The person-facing surfaces assessed were pray explain, pray search, command help, render-check guidance, and empty and error states. The hierarchy and copy are consistent across Rust, Ruby, and TypeScript, and a person can complete each task. Search has no interactive loading state. Long related references do not wrap specially on narrow terminals and remain a later human-review item.

The following checks completed successfully:

- cargo test --workspace --locked: complete workspace passed after the fixture fix.
- cargo clippy --workspace --all-targets --all-features --locked -- -D warnings: passed.
- cargo fmt --all --check: passed after the final fixture edit.
- cargo llvm-cov --workspace --summary-only --fail-under-lines 65: 75.99 percent line coverage.
- TypeScript core tests: 259 passed; all-files line coverage was 77.70 percent.
- TypeScript CLI tests: 68 passed.
- TypeScript type checks and Biome checks: passed for both packages.
- TypeScript circular-dependency checks: passed; the CLI check skipped 43 external pray-core imports.
- Ruby tests: 385 examples, 0 failures.
- RuboCop: 212 files inspected, no offenses.
- RBS validation: passed.
- cargo deny check advisories licenses bans sources: all four policies passed; duplicate-crate and three unused-license-allowance warnings remain.
- cargo machete: no unused Rust dependencies.
- npm audit: no vulnerabilities.
- bundler-audit check --update: no vulnerabilities in the updated advisory database.
- make size-check: passed. The Rust binary was 8,910,272 of 9,500,000 bytes; the Ruby gem was 118,272 of 131,072 bytes; the npm archive was 132,853 of 150,000 bytes, 572,022 of 650,000 unpacked bytes, and 339 of 360 entries.
- make loc-check: 138 warnings and no hard-limit failures.
- Release changelog, version, crate status, registry status, and RubyGems environment checks: passed.
- GitHub release notes preview: produced the 1.26.0 heading and the three coordinated release bullets.

The dependency review was a release baseline rather than a complete freshness and upstream-reputation audit. No package versions or dependency graph entries changed during release preparation.

## Next

- Tag and publish 1.26.0 in dependency order.
- Refresh the AUR checksum from the tagged archive before publishing its package update.
- Decide separately whether to remove the remaining dependency-policy warnings and the JSR command-wrapper warning.
