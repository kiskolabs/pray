# Prepare 1.26.3 release

## Decisions

Prepare version 1.26.3 dated 2026-11-12 without committing, pushing, tagging, publishing, or changing distribution checksums. Keep the Unreleased headings empty and move the coordinated release notes under the dated version heading.

Treat the AUR checksum as a post-tag task because the 1.26.3 source archive does not exist during preparation.

Product changelog scope is managed-span adopt when the destination body already matches the fresh render while the lock ideal is stale (RFC 0121). The Ruby search CLI encoding assertion fix is test-only and stays out of CHANGELOG.md.

## Effects

The Rust workspace, npm and JSR packages, Ruby gem, lockfiles, generated-by markers, package metadata, and four changelogs now agree on version 1.26.3.

The release dry run completed. npm and JSR package dry runs and the Ruby gem build completed without publishing.

`npm audit --omit=dev --json` and full `npm audit --json` reported no vulnerabilities. `bundler-audit check --update` reported no vulnerabilities.

The person-facing surfaces assessed were the root and package changelogs and release command output. The changelog hierarchy states one install recovery outcome. These terminal surfaces have no interactive loading or empty state, retain standard terminal wrapping on narrow displays, and let a person identify the release change. No screenshot is needed for text-only output.
