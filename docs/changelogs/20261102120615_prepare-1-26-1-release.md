# Prepare 1.26.1 release

## Participants

Andrei Makarov (@amkisko)

## Decisions

Prepare version 1.26.1 dated 2026-11-02 without committing, pushing, tagging, publishing, or changing distribution checksums. Keep the Unreleased headings empty and move the coordinated release notes under the dated version heading.

Treat the AUR checksum as a post-tag task because the 1.26.1 source archive does not exist during preparation.

Stop before tagging until the release operator decides how to repair the missing 1.26.0 GitHub history. Commit `354b6f4` prepared 1.26.0, and the coordinated package registries contain 1.26.0, but GitHub has neither a `v1.26.0` tag nor a release for it.

## Effects

The Rust workspace, npm and JSR packages, Ruby gem, lockfiles, generated-by markers, package metadata, and four changelogs now agree on version 1.26.1.

The release dry run completed. The unpublished pray-core 1.26.1 dependency prevented Cargo from resolving dependent crates from crates.io, so the release script used its expected local cargo check fallback for pray-transport and pray-cli. npm and JSR package dry runs and the Ruby gem build completed without publishing.

The npm release checks reported seven moderate audit entries from one transitive development advisory. `npm audit --omit=dev --json` reported no production vulnerabilities. The named release artifacts and circular-dependency lint commands are not affected because the artifacts omit the development graph and the lint configuration does not provide `projectService.allowDefaultProject` patterns. The dependency record preserves the scope and the future reassessment trigger.

The person-facing surfaces assessed were the root and package changelogs, `pray explain` dependency labels, rendered-destination drift errors, and release command output. The changelog hierarchy separates the two corrections. `pray explain` distinguishes required dependencies, optional referrals, and advisory related prayers. Drift errors name the destination and mismatch. These terminal surfaces have no interactive loading or empty state, retain standard terminal wrapping on narrow displays, and let a person identify the release changes and recovery path. No screenshot is needed for text-only output.

The following checks completed successfully:

- `cargo run -q -p pray-cli --locked -- install`: 23 packages and one local file checked; Prayfile.lock and AGENTS.md unchanged.
- `cargo run -q -p pray-cli --locked -- plan`, `verify`, `drift --semantic`, and plain `drift`: all exited successfully; plan reported Prayfile.lock and AGENTS.md unchanged.
- `make release-dry-run`: Rust, npm, JSR, and Ruby package checks and builds completed without publishing.
- `cargo test --workspace --locked`: complete workspace passed.
- `cargo clippy --workspace --all-targets --all-features --locked -- -D warnings`: passed.
- `cargo fmt --all -- --check`: passed.
- `cargo llvm-cov --workspace --summary-only --fail-under-lines 65`: 76.02 percent line coverage.
- TypeScript core tests: 263 passed.
- TypeScript CLI tests: 70 passed.
- TypeScript type checks, Biome checks, and circular-dependency checks: passed for both packages.
- Ruby tests: 389 examples, 0 failures.
- RuboCop: 213 files inspected, no offenses.
- RBS validation: passed.
- `cargo deny check advisories licenses bans sources`: all four policies passed; known duplicate-crate and unused-license-allowance warnings remain.
- `cargo machete`: no unused Rust dependencies.
- `npm audit --omit=dev --json`: no production vulnerabilities.
- `npm audit --json`: seven moderate development entries from one assessed advisory.
- `bundler-audit check --update`: no vulnerabilities in the updated advisory database.
- `make size-check`: passed. The Rust binary was 8,927,920 of 9,500,000 bytes; the Ruby gem was 118,784 of 131,072 bytes; the npm archive was 133,333 of 150,000 bytes, 574,403 of 650,000 unpacked bytes, and 339 of 360 entries.
- `make loc-check`: 137 warnings and no hard-limit failures.
- Release changelog, version, crate status, registry status, and RubyGems environment checks: passed.
- `scripts/release/github.sh --notes-only --version 1.26.1`: produced the two coordinated release bullets.

The release-state check found 1.26.0 on all coordinated registries: three crates.io crates, two npm packages, the Ruby gem, and two JSR packages. The GitHub tag and release endpoints returned 404, and the latest GitHub Release remains v1.25.0. No remote state changed during this check.

The 1.26.1 candidate is absent from all eight coordinated registry packages. No registry version conflict blocks publication.

The dependency review covered the release graph and the surfaced advisory. It was not a complete freshness or upstream-reputation audit. No dependency versions or graph entries changed during release preparation.
