# Prepare 1.26.2 release

## Decisions

Prepare version 1.26.2 dated 2026-11-06 without committing, pushing, tagging, publishing, or changing distribution checksums. Keep the Unreleased headings empty and move the coordinated release notes under the dated version heading.

Treat the AUR checksum as a post-tag task because the 1.26.2 source archive does not exist during preparation.

Product changelog scope is the coordinated resolve and tree-hashing speedups across Rust, Ruby, and TypeScript. Maintainer pressure-bench scripts, ceilings, and amkisko prayer consumer wiring stay outside CHANGELOG.md.

Split Ruby tree hashing into `package_spec_tree_hash.rb` so `package_spec.rb` stays under the 300-line hard ceiling after the streaming digest change.

## Effects

The Rust workspace, npm and JSR packages, Ruby gem, lockfiles, generated-by markers, package metadata, and four changelogs now agree on version 1.26.2.

The release dry run completed. The unpublished pray-core 1.26.2 dependency prevented Cargo from resolving dependent crates from crates.io, so the release script used its expected local cargo check fallback for pray-transport and pray-cli. npm and JSR package dry runs and the Ruby gem build completed without publishing.

`npm audit --omit=dev --json` and full `npm audit --json` reported no vulnerabilities. `bundler-audit check --update` reported no vulnerabilities.

The person-facing surfaces assessed were the root and package changelogs and release command output. The changelog hierarchy states one performance outcome. These terminal surfaces have no interactive loading or empty state, retain standard terminal wrapping on narrow displays, and let a person identify the release change. No screenshot is needed for text-only output.
