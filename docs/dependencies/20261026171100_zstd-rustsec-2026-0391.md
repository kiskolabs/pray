# zstd RUSTSEC-2026-0391

## Dependency

zstd 0.14.2 (Cargo.lock), used by pray-core and pray-cli.

## Symptom

cargo deny check advisories fails during 1.24.0 release preparation. Abandoned stream data on a reused zstd context can leak into the next stream.

## Evidence

RUSTSEC-2026-0391. cargo deny reported zstd 0.14.2 with solution Upgrade to >=0.14.3.

## Suggested fix

cargo update -p zstd. Observed lock move to zstd 0.14.3; advisories check then passed.

## Next

Ship with 1.24.0.
