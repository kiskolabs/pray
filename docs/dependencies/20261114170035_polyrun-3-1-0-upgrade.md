# polyrun 2.2.8 to 3.1.0 upgrade

## Dependency

polyrun development dependency in rubygems/pray-cli.
Manifest: Gemfile and pray-cli.gemspec now declare ~> 3.1 (was ~> 2.2).
Lockfile: Gemfile.lock pins polyrun 3.1.0 (was 2.2.8), checksum sha256=7e14fc57e2a36d8d17d9f5cb5f15cd689cf5b40e07b731da25d808b61da414e0.
Classification: dev or test only (parallel RSpec and coverage merge; not a runtime dependency of the published gem).

## Decisions

- Raise the floor to ~> 3.1 to take the latest registry line.
- Adapt spec/spec_helper.rb for the 3.0 hard cut: require polyrun/rspec_support and Polyrun::RSpecSupport (RFC-0007).
- Skip product CHANGELOG.md: no user-facing pray-cli contract change.
