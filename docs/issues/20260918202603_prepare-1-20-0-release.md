# Prepare 1.20.0 release

## Participants

Andrei Makarov

## Decisions

Cut 1.20.0 from publish row preservation, explicit re-sign, distribution page identity labels, trailing local compose drift, and skip-published-crate release resume already on main. Minor bump: operators keep an unchanged published version when a later publisher uses a different label, re-sign a local root version with pray publish --resign, read publisher names as claims on the package page, keep pray drift clean after install adds a trailing local compose file, and skip a crate on make release-all when that version already exists on crates.io. 1.19.0 is already tagged and pray-core 1.19.0 is on crates.io. Keep 2.0.0 for removing deprecated target, output, agent, skills, skill, and spec.skills. RFC 0061 stays Proposed through 2026-09-28. Leave Dependabot branches unmerged. Do not tag or publish from this pass. Leave Homebrew until registry publish.

## Effects

Workspace Cargo.toml, npmjs/pray-cli package.json, TypeScript PACKAGE_VERSION, and Ruby Pray::VERSION all read 1.20.0. bundle lock in rubygems/pray-cli rewrote Gemfile.lock with PATH gem pray-cli 1.20.0 and did not bump unrelated gems. cargo check --workspace --locked finished. cargo run -p pray-cli --locked -- install rewrote Prayfile.lock generated_by from pray 1.19.0 to pray 1.20.0. Package pins stayed the same. manifest_hash stayed sha256:80582fcd5c25b03373e3b837d46233f09419014505e2ac7e5974e171f08860ca.

make release-dry-run packaged pray-core 1.20.0 (187 files, 945.6KiB, 186.1KiB compressed) and the upload aborted for dry-run. pray-transport and pray-cli dry-run fell back to cargo check because crates.io does not have pray-core 1.20.0. npm pack produced pray-cli 1.20.0 (259 tests passed, 0 failed; package size 306.3 kB). ./scripts/release/rubygems.sh --dry-run built pray-cli 1.20.0 (320 examples, 0 failures). ./scripts/release/changelog_test.sh printed changelog notes tests passed. ./scripts/release/github.sh --notes-only --version 1.20.0 printed the 1.20.0 heading and five bullets. ./scripts/release/versions_test.sh printed coordinated version tests passed, including live next coordinated version 1.20.0.

Operator surface assessed: pray help publish. Hierarchy is a one-line action, then Usage with dest flags including --resign, then remotes, signing-key, legacy digest, and --resign copy. Interactive flags are --root, --server, --to, --dry-run, --signing-key, and --resign. Empty dest with remotes is the omitted-flag path. A person can finish publish from that help when remotes exist or dest flags are known. Remaining for a human: visual review of Publisher label, Package signature, and Content digest on a live distribution package page.

No tag and no registry publish from this pass.

Later pass 20260918211600: annotated tag v1.20.0 points at fb8777d. GitHub Release https://github.com/kiskolabs/pray/releases/tag/v1.20.0 is published. No registry publish. Homebrew stayed on the previous formula.

Publish crates.io, npmjs, and RubyGems through the manual release process. Then bump Homebrew with make bump-homebrew. Close GitHub issue 31 after that ship.
