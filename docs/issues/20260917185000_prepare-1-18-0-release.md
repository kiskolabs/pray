# Prepare 1.18.0 release

## Participants

Andrei Makarov

## Decisions

Cut 1.18.0 from git catalog clone efficiency, subdirectory worktrees, registry metadata reuse, and update --latest skip already on main. Minor bump: operators clone a used git catalog without unused package blobs, skip unused catalogs, fetch a used catalog once on update, keep packages from two sources that share a clone URL with different subdir values, share one object store for those checkouts, import signing keys with pray trust import-repo after a subdir-only clone, reuse registry package metadata during one command, skip a second resolve when update --latest does not rewrite constraints or upstream pins, and fetch torrent piece lists only when a registry lists torrent. Keep 2.0.0 for removing deprecated target, output, agent, skills, skill, and spec.skills. Leave Dependabot branches unmerged. Tag v1.18.0 and publish the GitHub Release from this pass. Do not publish crates.io, npm, or RubyGems from this pass. Leave Homebrew until registry publish.

## Effects

Workspace Cargo.toml, npmjs/pray-cli package.json, TypeScript PACKAGE_VERSION, and Ruby Pray::VERSION all read 1.18.0. bundle lock in rubygems/pray-cli rewrote Gemfile.lock with PATH gem pray-cli 1.18.0 and did not bump unrelated gems. cargo check --workspace --locked finished. cargo run -p pray-cli --locked -- install rewrote Prayfile.lock generated_by from pray 1.17.0 to pray 1.18.0. Package pins stayed the same. manifest_hash stayed sha256:54f67e7f0bba02adc72e1dbc830961fe7b43d7cd11e04fdce3563661fe3cbaa8.

make release-dry-run packaged pray-core 1.18.0 (182 files, 919.4KiB, 181.8KiB compressed) and the upload aborted for dry-run. pray-transport and pray-cli dry-run fell back to cargo check because crates.io does not have pray-core 1.18.0. npm pack produced pray-cli 1.18.0 (243 tests passed, 0 failed; package size 295.6 kB). ./scripts/release/rubygems.sh --dry-run built pray-cli 1.18.0 (304 examples, 0 failures).

Later pass 20260917190000: annotated tag v1.18.0 points at 16a717b. GitHub Release https://github.com/kiskolabs/pray/releases/tag/v1.18.0 is published. No registry publish. Homebrew stayed on the previous formula.

## Next

Publish crates.io, npmjs, and RubyGems through the manual release process. Then bump Homebrew with make bump-homebrew.
