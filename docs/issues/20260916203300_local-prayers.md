# Local prayers as path-source packages

## Participants

Andrei Makarov

## Decisions

Local prayers live under a path source directory of the author's choosing. prayers/ is the default when prayer init adds a source. Version and a package archive are not required until pack or publish. pray prayer init with a Prayfile writes that tree, adds source "local" when needed, and declares pray "local/project" once. The default name is project. Names matching v plus digits are reserved for the distribution layout. .agents/project.md stays a compose shortcut for one local file.

An unqualified package name uses the unique path source even when a git source also exists. A namespaced token such as local/project selects that path source when several sources exist. A second pray line with path: is not used.

A later pass changed the locator from a hardcoded prayers/<name>/ path package declaration to a path source.

A later pass declared pray "local/project" so the source handle is in the package token.

A later pass changed the locator from a hardcoded prayers/<name>/ path package declaration to a path source.
