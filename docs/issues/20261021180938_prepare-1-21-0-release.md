## Decisions

- Prepare 1.21.0 from `main`. The release contains user-visible fixes, a Rust minimum-version change, and cross-language behavior updates, so it uses a minor version increment from 1.20.0.
- Align the Rust workspace, npm package, TypeScript generated-by constant, and Ruby gem at 1.21.0.
