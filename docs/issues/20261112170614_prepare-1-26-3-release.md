# Prepare 1.26.3 release

## Decisions

Prepare version 1.26.3 dated 2026-11-12. Keep preparation separate from committing, pushing, tagging, publishing, and changing distribution checksums.

Use a patch release for managed-span adopt-when-identical (RFC 0121): install refreshes a stale lock when the on-disk active body already matches the fresh render ideal, and keeps fail-closed recovery without a force flag.

Keep the AUR package at 1.26.0 until a tagged archive for this release exists and its checksum can be measured.

Registries still list 1.26.1 as latest for the checked package names while git already contains an unpublished 1.26.2 preparation. Do not hide that gap. Decide whether to publish 1.26.2 first, skip its registry publish, or only ship 1.26.3 after tagging.

## Effects

All coordinated version declarations and changelogs now identify 1.26.3. The release dry run built or checked the Rust, npm, JSR, and Ruby packages without publishing them.

The complete validation record is in the matching changelog note.

The 1.26.3 candidate is not present on crates.io, npm, or RubyGems for the checked package names. Live latest observed during preparation: crates.io / npm / RubyGems `pray-cli` at 1.26.1.
